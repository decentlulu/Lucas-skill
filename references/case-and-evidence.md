# 案例与证据规范

## 一、证据等级

按可靠性由高到低使用：

1. 当前有效的法律法规、监管文件、审计数据、公司公告、原始数据库和一手研究。
2. 权威机构报告、同行评审研究、可靠财务与运营数据。
3. 高质量二手研究、专业媒体、正式案例研究。
4. 访谈、内部材料、经验观察和 Lucas 笔记。
5. 传闻、流行故事、未经核实的名人名言。

低等级材料可用于生成假设，不可单独支撑高风险结论。出现冲突时说明来源、口径、时间和可能原因。

## 二、案例选择

使用案例前检查四种相似性：

- **机制相似**：因果机制是否相同？
- **情境相似**：行业、规模、制度、技术和阶段是否相近？
- **约束相似**：资源、法域、治理和利益格局是否相近？
- **结果可比**：指标口径与时间跨度是否一致？

优先使用一正一反两个案例，避免只讲成功故事。案例表达建议采用：

`背景 → 决策 → 机制 → 结果 → 局限 → 对当前问题的可迁移启示`

## 三、中外历史案例

- 先核实时代背景、主体、制度和基本事实。
- 提炼治理、联盟、激励、后勤、组织或合法性机制，不照搬结论。
- 明确“历史解释存在争议”或“此处仅作机制类比”。
- 不把《鬼谷子》《孙子兵法》或西方经典中的警句当作经验数据。
- 不用单一文化标签解释复杂行为。

## 四、咨询公司方法论

可以使用公开且普遍认可的框架，如麦肯锡 7S/三层面、BCG 矩阵、波特五力、安索夫矩阵、价值链、金字塔原理、精益和业务流程再造。不要暗示获得了咨询公司的专有内部资料；方法名称、归属或版本不确定时查证原始或官方来源。

## 六、断言标记

在复杂或高风险分析中按需标注：

- **事实**：来源明确、可核实。
- **推断**：由事实推导，写明逻辑。
- **假设**：尚待验证，写明验证方法。
- **类比**：用于启发，写明差异。
- **建议**：基于目标和价值取舍。
